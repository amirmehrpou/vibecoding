# گردونه شانس — Pixel Perfect

پیاده‌سازی UI گردونه شانس با HTML و CSS مطابق طرح مرجع.

## ویژگی‌ها

- پس‌زمینه تیره با گرادیان
- گردونه ۶ قسمتی با حاشیه بیرونی، حلقه داخلی و نقطه مرکزی نئون قرمز
- ۶ خط جداکننده از مرکز به لبه (هر ۶۰°، با آفست ۳۰° تا بخش بالا زیر نشانگر باشد)
- مثلث نشانگر در بالای گردونه
- متن افقی در **وسط هر بخش** (بین دو خط مجاور، بدون چرخش متن)
- دکمه «چرخوندن» با سایه درخشان
- فونت [Vazirmatn](https://fonts.google.com/specimen/Vazirmatn)
- انیمیشن چرخش اختیاری با JavaScript

## بخش‌های گردونه (ساعت‌گرد از بالا)

| زاویه مرکز بخش | متن |
|----------------|-----|
| ۰° (بالا) | ۱ میلیون تومان جایزه |
| ۶۰° | پوچ |
| ۱۲۰° | ۱۰ میلیون تومان جایزه |
| ۱۸۰° | پوچ |
| ۲۴۰° | ۱۰۰ میلیون تومان جایزه |
| ۳۰۰° | پوچ |

خطوط جداکننده در زوایای ۳۰°، ۹۰°، ۱۵۰°، ۲۱۰°، ۲۷۰° و ۳۳۰° (نسبت به بالا) رسم شده‌اند؛ متن هر بخش در زاویه میانی همان فضا قرار دارد.

## جزئیات پیاده‌سازی

- **خطوط:** SVG — شش `line` از مرکز `(124, 124)` به لبه دایره
- **متن:** با CSS variable `--angle` و transform سه‌مرحله‌ای (`rotate` → `translateY` → `rotate` معکوس) برای افقی ماندن متن
- **شعاع متن:** `--radius: 68px` برای «پوچ» و `64px` برای جایزه‌ها

## اجرا

فایل `index.html` را در مرورگر باز کنید:

```bash
open index.html
```

یا با یک سرور محلی:

```bash
npx serve .
```
